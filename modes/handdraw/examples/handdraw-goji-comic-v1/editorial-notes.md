# 本期修订与画面边界

保留用户的低电量开场、枸杞超人、成分盾牌、左右对比、办公室食用搭配和绿色电量收尾，重新绘制本期职员与场景。原稿见 `source-copy.md`。

- 红枸杞与黑枸杞的成分特点不可混写，花字统一为“枸杞多糖 / 玉米黄质”；没有“高倍”含量或某商品含量保证。
- 去掉“专管肝肾亏虚和用眼过度”“给身体充满电”等确定疗效表述；保留传统中医的滋补肝肾、益精明目语境。漫画黑气、盾牌和电量不作为真实治疗效果，片中标注。
- 左右分屏保留，但不把暗红、下沉或汤色直接标作劣质证据；改为提醒颜色和浮沉不能单独定品质。
- 未提供产地、采收、加工、检测资料和商品标签；不把自家果园、头茬、不熏硫、不染色、多道洁净烘焙、免洗即食或价格作为已证实商品事实。包装为原创手绘示意。
- 开袋即食改为先看食用说明，不泛化免洗或直接食用资格；删除“嚼着吃更营养”的笼统优劣断言。
- 保留购买意向表达，结尾补充适量食用和休息；绿色100%为离屏休息后的漫画情绪表达，非食用前后实验。
