# 手绘模式

- 先读 README.md 和 content/presets/handdraw-story-code-v1.json，再读本期文案；本期明确要求优先。预设由助手落实，不是渲染器自动加载接口。
- 新片按 WORKFLOW.md 执行；本期源代码放根目录projects的独立版本内，复用本模式依赖。明确选声、实际配音参数、实测时码及Composition id必须对应；只改画面时优先复用身份匹配的音频。
- 默认《井里的月亮》的暖白纸张、淡彩墨线、简洁情境，真实路径逐笔描线、局部填色和笔尖跟随。不采用日系动画电影的美术目标。
- 一两句旁白对应一个具体场景，按真实声音时码排镜。新稿必须绘制新场景，不得只替换旧猴子字幕，不做 PPT 知识卡。
- 桌面助手准备所有内部绘制代码、JSON、素材和时码；不转交用户。原示例绘图脚本硬编码具体故事，不是任意文案绘图器。
- 延用独立连续旁白、底部字幕、1080p/30fps H.264/AAC。先短预览和代表帧，再全片。默认不加配乐；本期明确要求可覆盖。
- 未实际听验不称逐字正确、音色合格。技术解码不能代替主观验收；静态推拉不称完整人物动画。
- 食养内容区分传统中医语境与现代证据，不承诺疗效，不捏造检测、产地、品牌或产品资质。包装示意要明确标注。
- 中药系列如沿用既有角色要求：女主明确成年26—30岁，明艳、有活力、丰润匀称；声音成熟有磁性，不用播音腔。角色和音色先实际验收，不套给通用寓言。
- 保留版本、素材来源与实际验证记录。后续修改本目录不应影响其他模式。
